## 1. 定位（Positioning）

**一句话定位：**
> 一个人 + 一个 AI Agent，两天半从零搭出一家游戏工作室的**全套管线**，并产出一款可联机的军棋变体桌游《烽决》。

**差异化（为什么这个故事有人看）：**
- 不是「我用 AI 写了个游戏 Demo」——那是陈词滥调。
- 而是「**我用 AI 当我的整支工作室团队**（PM/前端/后端/美术/音效/DevOps 一人分饰，靠 Agent 的专家模式切换）」，且**全管线可验证**（130 次提交、9.5 千行核心源码、CI 绿、线上可玩）。
- 受众错位优势：你的博客读者是**技术/AI 人群**（AIGC 系列读者），而游戏又天然破圈——技术故事拉开发者，游戏本体拉玩家，双受众。

## 3. 宣发路线图（分阶段、分渠道）

**总原则：先稳交付，再讲故事，最后放量。** 博客是「可分享资产」，应在交付稳定后首发。

| 阶段 | 目标 | 渠道 | 内容形态 | 出口 |
|---|---|---|---|---|
| **P0 稳交付（门禁）** | 拿到稳定可玩链接 | — | 前端 Pages 重部署 + 线上 E2E 冒烟通过 | `duel.tmoc.qzz.io` 实测可玩 |
| **P1 博客首发** | 立故事 + SEO | t1mmoc.github.io（【AIGC】系列） | 旗舰长文 + 试玩 CTA | 博客链接 |
| **P2 技术社区** | 引流开发者 | 掘金 / 知乎(AIGC·独立游戏) / V2EX「分享创造」/ 少数派 | 博客 syndicate + 讨论 | → 博客 & 游戏 |
| **P3 游戏社区** | 触达玩家 | indienova / B站(游戏开发·桌游) / 机核 / TapTap 发现 / 贴吧桌游吧·军棋吧 | 试玩 + 玩法 + 开发故事 | → 游戏 |
| **P4 视觉破圈** | 扩大受众 | 小红书(二次元视觉) / 抖音·B站 短视频 Demo | 30–60s 对战实录 + 美术特写 | → 游戏 |
| **P5 全球开发者** | 英文破圈 | Hacker News / Dev.to / Reddit r/gamedev | 英文版「1 person + 1 AI studio in 2.5 days」 | → GitHub & 游戏 |

**渠道选择依据（你的已知资产）：** 博客已有 AIGC 读者基本盘；picbot/hermes/tdchat 等项目的飞书/技术受众可交叉导流；游戏本体（军棋变体 + 二次元美术）天然适配 B站/小红书/indienova。

### 3.1 视频策略（最大流量杠杆）

游戏自带**二次元美术 + 30 个现成音效**（capture_hit / bomb_blast / teleport / base_revealed / victory 等），天然适配短视频，是比纯图文破圈更快的杠杆。

**4 类视频形态（按投产比排序）：**
| 形态 | 时长 | 内容 | 投放 | 说明 |
|---|---|---|---|---|
| **① 对战高光** | 15–30s | 录最爽瞬间：炸弹同归于尽、传送门突袭、暗棋揭示、胜利 | 抖音/视频号/小红书 | 配现成音效、无需配音即吸睛，**转化最快** |
| **② 两天半极速剪辑** | 60–90s | 提交图滚动 + 3 条 worktree 分屏 + WorkBuddy 对话闪回 + 美术/音效快剪 | B站/抖音 | 立「AI 工作室」人设，讲透两天半故事 |
| **③ 开发 Vlog / Dev-log** | 3–8min | 屏录讲「我怎么用一个 Agent 当全栈团队」，引数据清单 | B站 | 社区黏性高，技术受众最爱 |
| **④ 玩法教学** | 30s | 3 句话讲清军棋变体 + 铁道/传送门/假基地 | 全平台 | 降低理解门槛，配图文 |

**制作与投放：**
- 制作：录屏用 OBS / ShareX；音效直接复用项目 30 wav；也可调用 WorkBuddy 的 VideoGen 生成图生视频/短视频素材。
- 节奏：**视频与博客同步首发**——博客给深度与 SEO，视频给流量；每条视频简介挂博客链接 + 试玩链接，互相导流。
- 平台分工：B站（长版 + Dev-log，社区黏性）、抖音/视频号（15–30s 高光，病毒扩散）、小红书（视觉/二次元向图文+短视频）。

### 3.2 如何找到合适的 WorkBuddy 专家（执行侧加速）

本宣发是「多切片」工程（写稿 / 脚本 / 增长 / 设计 / 发行），靠单一会话不如**借 WorkBuddy 专家体系分派**。你是当前会话的 **SeniorProjectManager（统筹层）**，执行时把切片委派给专项专家即可。

**入口与机制：**
- 左侧栏 **「专家」** → 进入 Expert Center → 按分类浏览 / 搜索 → 与任意专家开聊获取专项帮助。
- 协作模式（PM 视角）：我出方案与口径 → 调用对应专家产出具体物料 → **你终审**。例：让「文案专家」起草旗舰篇 → 「短视频专家」出 15s/60s 两版脚本 → 你定稿。
- 注意：专家用于**加速执行**；方向 / 定位 / 口径红线仍由本备忘（PM）统一把控，避免多渠道口径打架。

**与本宣发相关的专家方向（按需开聊）：**
| 专家方向 | 能帮你做的 |
|---|---|
| 文案 / 内容营销 | 代笔旗舰博客、小红书/抖音短文案 |
| 短视频 / 脚本 | 视频分镜、口播稿、标题钩子 |
| 增长 / 社媒运营 | 各平台发布节奏、标签策略、冷启动 |
| SEO / 独立站 | 博客收录、关键词（「AI 游戏」「一人工作室」） |
| 设计 | 封面图/缩略图（结合项目现有美术资产） |
| 独立游戏发行（若存在） | indienova / TapTap / itch.io 上架与社区运营 |
