## 2. 录制/剪辑要点
- git 图用 `git log --oneline --graph` 截图后做位移缩放；数字用数据清单最终值。
- 三屏分列用 OBS 多视图或后期画中画，避免录屏卡顿。
- 对话闪回打码敏感信息（remote URL、token 已不入库，仍建议遮掉账号）。
- BGM 用项目配乐 worktree 的 wav，避免版权风险。
